================================================================================
MESHWORLD LEVEL SYSTEM v3 — Level Swapper with Custom Vtable Allocation
================================================================================

v3 NEW FEATURES:
  - Custom vtable allocation: each level gets its OWN writable vtable copy.
    VTABLE commands now ALWAYS work per-level, even after SET/SWAP redirects
    the board ctor to another level. The ctor writes the custom vtable, not
    the original .data vtable.
  - COPYVT A B — copy ALL 36 vtable entries from level B into level A's
    custom vtable. Use with SET: SET 1 2 gives Level 1 Beginner's struct,
    then COPYVT 1 2 gives it Beginner's vtable as a starting point.

Level Numbers:
  1=WarmUp  2=Beginner  3=Intermediate  4=Dizzy     5=Tower
  6=Up      7=Neon      8=Expert        9=Odd       10=Toob
  11=Wobbly 12=Glass    13=Sky          14=Master   15=Impossible

Commands (in CONFIG SECTION below):
  SET A B      — One-way redirect. Level A gets level B's board ctor + struct
                 size. Level A still uses its own custom vtable (modify with
                 VTABLE). Tip: use COPYVT A B after SET to copy B's vtable.

  COPYVT A B  — Copy ALL 36 vtable entries from level B's custom vtable into
                 level A's custom vtable. Useful with SET to start from B's
                 vtable layout, then customize individual slots with VTABLE.

  SWAP A B    — Full level swap. Redirects the board constructor for level A
                to level B's ctor (with B's struct size) and vice versa.
                This swaps EVERYTHING: geometry, objects, physics, camera.
                Custom vtables stay independent — VTABLE still works per-level.

  SWAPOBJ A B — Swap only vtable[32] (Board_Setup) between two levels.
                Changes which OBJECTS appear without changing the board ctor
                or geometry.

  SWAPGEO A B — Swap only vtable[18] (setup function) between two levels.
                Changes which .MESHWORLD geometry loads without changing the
                board ctor or objects.
                WARNING: May crash if the swapped setup function writes to
                board offsets beyond the original level's struct size.
                Use SET instead for safe cross-struct-size swaps.

  SETUP A func — Replace level A's vtable[18] (setup function) with a named
                 function. Changes which .MESHWORLD loads.

  ADD A func   — Add an extra function call after level A's setup function.
                 Creates a trampoline via VirtualAlloc that chains the calls.
                 Use to run additional setup logic per level.

  VTABLE A slot func — Write any function into any vtable slot for level A.
                     Writes to the level's CUSTOM vtable — always works,
                     even after SET/SWAP.
                     <slot> can be a number (0-35) or a name:
                       dtor(0) update(1) setup(18) initscene(19)
                       renderdynamic(24) dispatchcollision(29)
                       boardsetup(32) levelspecific(33)
                     <func> can be a name from the function table, 0xHEXADDR,
                     or 0/null to clear the slot.
                     Examples:
                       VTABLE 1 setup Scene_SetupLevelCascade
                       VTABLE 3 0 Beginner_dtor
                       VTABLE 5 boardsetup 0x0041C5B0
                       VTABLE 1 9 Odd_DispatchColl
                       VTABLE 1 2 0          ; clear slot 2

  DUMP        — Log the full 36-entry vtable for every level to the .log file.

  RESET       — Restore all original values (push+call+custom vtable[0-35]).

Level names can be used instead of numbers (case-insensitive):
  WarmUp, Beginner, Intermediate, Dizzy, Tower, Up, Neon, Expert,
  Odd, Toob, Wobbly, Glass, Sky, Master, Impossible

Function names for SETUP, ADD, and VTABLE:
  Setup functions (vtable[18]):
    GetLevelPath, Scene_SetupLevelCascade, Scene_LoadLevel2,
    Scene_LoadLevel3, Scene_LoadLevel4, Scene_SetupLevel5,
    Scene_SetupLevel6, Scene_SetupLevel7, Scene_SetupLevel9,
    Scene_SetupLevelUp, Scene_SetupLevel10, Scene_SetupLevelDark,
    CreateBumper, FUN_00417640, FUN_00417F20
  Destructors (vtable[0]):
    WarmUp_dtor, Beginner_dtor, Intermediate_dtor, Dizzy_dtor,
    Tower_dtor, Up_dtor, Neon_dtor, Expert_dtor, Odd_dtor, Toob_dtor,
    Wobbly_dtor, Glass_dtor, Sky_dtor, Master_dtor, Impossible_dtor
  InitScene (vtable[19]):
    WarmUp_InitScene, Beginner_InitScene, Up_InitScene,
    Neon_InitScene, Odd_InitScene, Toob_InitScene
  RenderDynamic (vtable[24]):
    WarmUp_RenderDyn, Beginner_RenderDyn, Tower_RenderDyn,
    Odd_RenderDyn, Toob_RenderDyn, Wobbly_RenderDyn, Sky_RenderDyn
  DispatchCollision (vtable[29]):
    WarmUp_DispatchColl, Beginner_DispatchColl, Intermediate_DispatchColl,
    Dizzy_DispatchColl, Tower_DispatchColl, Up_DispatchColl,
    Neon_DispatchColl, Expert_DispatchColl, Odd_DispatchColl, Toob_DispatchColl
  Board_Setup (vtable[32]):
    WarmUp_BoardSetup, Beginner_BoardSetup, Dizzy_BoardSetup
  Other:
    Level_InitScene, Graphics_SetProjection
  Or use hex: 0x0041B130, 0x00425040, etc.
