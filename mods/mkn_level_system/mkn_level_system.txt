================================================================================
MESHWORLD LEVEL SYSTEM v4 — Custom Vtables + Safe Struct Allocation
================================================================================

v4 FIX:
  ALL 15 levels are now allocated at the maximum struct size (0x6498 = Master).
  This means you can freely mix-and-match vtable functions from different levels
  using ONLY VTABLE commands — no SET/SWAP needed. The board is always big enough.

  Custom vtable allocation (from v3) is retained — each level gets its own
  writable vtable copy, so VTABLE commands are fully independent per level.

Level Numbers:
  1=WarmUp  2=Beginner  3=Intermediate  4=Dizzy     5=Tower
  6=Up      7=Neon      8=Expert        9=Odd       10=Toob
  11=Wobbly 12=Glass    13=Sky          14=Master   15=Impossible

Commands (in CONFIG SECTION below):
  VTABLE A slot func — Write any function into any vtable slot for level A.
                     Writes to the level's CUSTOM vtable — always works.
                     <slot> can be a number (0-35) or a name:
                       dtor(0) update(1) setup(18) initscene(19)
                       renderdynamic(24) dispatchcollision(29)
                       boardsetup(32) levelspecific(33)
                     <func> can be a name from the function table, 0xHEXADDR,
                     or 0/null to clear the slot.
                     Examples:
                       VTABLE 1 setup Scene_SetupLevelCascade
                       VTABLE 1 9 Odd_DispatchColl
                       VTABLE 1 2 0          ; clear slot 2

  COPYVT A B  — Copy ALL 36 vtable entries from level B into level A's
                custom vtable. Quick way to start from another level's layout.

  SETUP A func — Same as: VTABLE A setup func

  SET A B      — Redirect level A's board ctor to level B's (changes struct
                 size + ctor). Rarely needed in v4 since all structs are max-size.
  SWAP A B    — Full level swap (ctor + struct).
  SWAPOBJ A B — Swap vtable[32] (Board_Setup) between two levels.
  SWAPGEO A B — Swap vtable[18] (setup) between two levels.
  ADD A func   — Add extra function call after level A's setup.
  DUMP        — Log full 36-entry vtable for every level.
  RESET       — Restore all original values.

Level names can be used instead of numbers (case-insensitive).

Function names for VTABLE, SETUP, and ADD:
  Setup functions (vtable[18]):
    GetLevelPath, Scene_SetupLevelCascade, Scene_LoadLevel2,
    Scene_LoadLevel3, Scene_LoadLevel4, Scene_SetupLevel5,
    Scene_SetupLevel6, Scene_SetupLevel7, Scene_SetupLevel9,
    Scene_SetupLevelUp, Scene_SetupLevel10, Scene_SetupLevelDark,
    CreateBumper, FUN_00417640, FUN_00417F20
  Destructors (vtable[0]):
    WarmUp_dtor, Beginner_dtor, Intermediate_dtor, Dizzy_dtor,
    Tower_dtor, Up_dtor, Neon_dtor, Expert_dtor, Odd_dtor, Toob_dtor,
    Wobbly_dtor, Glass_dtor, Sky_dtor, Master_dtor, Impossible_dtor
  InitScene (vtable[19]):
    WarmUp_InitScene, Beginner_InitScene, Up_InitScene,
    Neon_InitScene, Odd_InitScene, Toob_InitScene
  RenderDynamic (vtable[24]):
    WarmUp_RenderDyn, Beginner_RenderDyn, Tower_RenderDyn,
    Odd_RenderDyn, Toob_RenderDyn, Wobbly_RenderDyn, Sky_RenderDyn
  DispatchCollision (vtable[29]):
    WarmUp_DispatchColl, Beginner_DispatchColl, Intermediate_DispatchColl,
    Dizzy_DispatchColl, Tower_DispatchColl, Up_DispatchColl,
    Neon_DispatchColl, Expert_DispatchColl, Odd_DispatchColl, Toob_DispatchColl
  Board_Setup (vtable[32]):
    WarmUp_BoardSetup, Beginner_BoardSetup, Dizzy_BoardSetup
  Other:
    Level_InitScene, Graphics_SetProjection
  Or use hex: 0x0041B130, 0x00425040, etc.
