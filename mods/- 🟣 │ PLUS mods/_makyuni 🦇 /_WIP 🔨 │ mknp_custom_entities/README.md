# Custom Entities (HB+ Mod)

Spawn custom entities (Rotators, Pendulums, Gears, etc.) from MESHWORLD S1 ref points.

## Installation

Place `mkn_plus_custom_entities.dll` in the `Mods\` folder.

## Features

- Spawns custom entities at S1 GRID reference points in MESHWORLD files
- Supports AI types: Rotator, Pendulum, Looper, Gear, BigGear
- DAT property parsing for per-entity customization
- MESH property overrides for custom visual meshes
- Matches entity names: cEnt_XXX, REF:cEnt_XXX, C_entity_XXX, REF:C_entity_XXX
