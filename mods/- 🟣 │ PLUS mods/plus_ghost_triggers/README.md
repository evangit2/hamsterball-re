# Ghost Triggers (HB+)

HB+ port of the Rodent_Mods `_DONE ✔ │ ghost_triggers` mod.

## Files

- `GhostTriggersMod.cpp` — source code
- `HamsterballAPI.h` — copy of the HB+ API header
- `.dll` — compiled output (built by user in Visual Studio or via MinGW cross-compile)
