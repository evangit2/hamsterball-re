; diamond_weasel_config.txt
; Per-race DIAMOND medal times.
;
; The "Diamond Weasel" is a fifth, secret medal. On the results screen, when
; you finish a race faster than the per-race diamond threshold, a diamond
; weasel medal icon renders directly over the golden weasel medal (same spot).
; It's the 5th medal in the sequence (golden weasel, bronze, silver, gold,
; diamond), appearing ~165 frames (~3 medal gaps) after gold.
;
; --- HOW THE DIAMOND TIME IS CHOSEN (priority order) ---
; 1. racedata.xml  A <DIAMOND> element inside the race's existing block. The
;                  mod reads the SAME racedata.xml the game uses (in the game
;                  folder), matching each race the exact same way the game
;                  matches its other medal blocks. If a race's block has a
;                  <DIAMOND> tag, that value wins.
; 2. DLL defaults  If racedata.xml has no <DIAMOND> for a race (or the file is
;                  missing), the time baked into the DLL is used. Those are:
;                    WARM-UP 3.5     BEGINNER 12.3   INTERMEDIATE 14.0
;                    DIZZY 23.0      TOWER 24.0      UP 20.0
;                    NEON 28.0       EXPERT 29.0     ODD 12.0
;                    TOOB 25.0       WOBBLY 23.0     GLASS 30.0
;                    SKY 32.0        MASTER 40.0     IMPOSSIBLE 26.0
; 3. SECRET= below  These manual overrides (if present) take highest priority
;                  and let you tune a race without touching racedata.xml.
;
; ICON=<filename>      Optional. Results-screen icon. Defaults to
;                      diamondweasel.png in Textures\.
; MINIICON=<filename>  Optional. Time-Trial-menu mini icon. Defaults to
;                      diamondweasel-icon.png in Textures\.
;                      Drop your provided PNGs there.
;
; DIAMOND_DELAY=<frames>  Optional. How long after the GOLD medal appears
;                      before the diamond appears on the results screen.
;                      The game staggers medals 55 frames apart (bronze at
;                      845, silver at 900, gold at 955). Default 165 (3x the
;                      gold gap) = the diamond appears 3 medal-gaps after gold.

ICON=diamondweasel.png
MINIICON=diamondweasel-icon.png
DIAMOND_DELAY=165
