# Rodent Mods Catalog

All mods in this directory are authored by **RodentRacer**. Each mod is a `bass.dll` proxy mod for the original Hamsterball game.

The HB+ (`plus_*`) versions are maintained under `mods/- 🟣 │ PLUS mods/`.

## Done Mods

| Mod Folder              | Description                                | HB+ Version                  |
|-------------------------|--------------------------------------------|------------------------------|
| 8ball_hit_detect        | Detect when the player ball hits an 8-ball  | plus_8ball_hit_detect        |
| ghost_event             | `E:GHOST(file)` custom event for ghost replay| plus_ghost_event             |
| ghost_saver             | Save Time Trial ghost runs to `.ghost` files| plus_ghost_saver             |
| ghost_triggers          | `GT:` trigger zones for ghost balls         | plus_ghost_triggers          |
| half_size_p1            | Shrink player 1 ball to half radius         | plus_half_size_p1            |
| jump_mod                | Add jump force via keybind                  | plus_jump_mod                |
| level_warp              | `WARP(Name)` zones for level transitions    | plus_level_warp              |
| no_pause                | Disable pause during races                  | plus_no_pause                |
| water_mod               | Change water behavior                       | plus_water_mod               |

## Notes

- Mods in `mods/- 🟣 │ PLUS mods/` require the **Hamsterball Plus (HB+)** mod loader.
- `bass.dll` proxy mods run in the original game without HB+.
- Crash testing for HB+ versions must be done through the HB+ mod loader on a real Windows install.
